# CrewAI Team Builder

Build your own team of AI assistants on Windows — a Project Manager, Researcher, Reviewer, Analyst and more — then give them a task and chat with them like a group chat.

## Download

👉 **[Download the latest CrewAI_Setup.exe](../../releases/latest)**

Run it and follow the steps. No Python or technical setup needed — everything the app needs is inside the installer.

## What it does

- **Pick your team** — tick the roles you want; one leads and hands out the work.
- **Chat with your crew** — type a task, attach documents (PDF, Word, Excel, CSV…), get a clean answer.
- **Free on your PC** — runs AI models locally with Ollama. Nothing leaves your computer.
- **Or use cloud AI** — connect Claude, ChatGPT, Gemini, DeepSeek and more in one click with OpenRouter, or with your own API keys.
- **Updates itself** — new versions install automatically from inside the app.

## Requirements

- Windows 10 or 11 (64-bit)
- 8 GB RAM minimum; 16 GB or more recommended for local models
- About 6 GB free disk space for the app and a local model

## Safety

- API keys are stored encrypted on your PC and only sent to the provider you choose.
- Every update is digitally signed and checked before it installs.
- Uninstall from Windows **Settings › Apps** removes everything the app installed.
